Cómo operar

  1. Cambiar destinatario, asunto, cuerpo, pausar o ajustar fechas: edita data/config.json en GitHub.
  2. Probar sin enviar: Actions → Enviar bitacora → Run workflow → marca dry_run.
  3. Enviar una prueba a tu propio correo: Run workflow → marca prueba.
